## Descripcion general

aqui podras un programa en la que se le preguntara al usuario su nombre y su edad para validarle con un mensaje de alerta si es mayor o menor de edad, y la indicacion de lo que debe hacer, el programa esta hecho para que si el usuario ingresa valores invalidos no se dañe, si no que pueda indicarle al usuario que hizo alguna accion incorrecta hacia lo que se le pregunta, con un mensaje de alrta y tambien se maneja mensaje por consola.

## Caracteristicas

* Mostrar mensaje de alerta
* Interactuar con el usuario
* mensaje de error
